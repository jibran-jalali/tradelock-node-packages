- No wallet installation or manual account import remains. Open the page and select Buyer or Supplier.
- The public demo keys are bundled deliberately; anyone can use either wallet. This is not secure authentication, an encrypted wallet vault, or a system for real funds. The endpoint is fixed to loopback and signing refuses chains other than 31337.
- Node-reset detection was verified with the original contract integration. The native update preserves the same deployment block-fingerprint check, and the current isolated test suite also verifies wrong-chain refusal.
